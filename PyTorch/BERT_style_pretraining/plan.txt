Training:
    Words divided up by text_id not subtext
    Tokenised with BPE-Dropout per epoch
        => Sliding windows of 96 tokens each, stride 48, padding both to exclude part-words and to fill out last windows to 96 tokens
        => Training-words are read off disk at start of program along with text_wordoffsets and fed as one flat batch to the tokeniser
        => Tokeniser gives back flat std::vector<std::uint16_t> of tokens but should also generate token_wordoffsets and return that as well
        => Python then turns the flat tokens-vector into text-id bounded 96-token windows which are given to the DataLoader to batch up
            => Split tokens-list on text-boundaries first
            => The start and end of whole-words in each 96-token window can be found by counting up from both the 0th and 95th position until tokens in the token_wordoffsets is found: at the beginning we pad-out all tokens preceding the first token_wordoffsets one, and at the end we
            95th token: check 96th, if it's in token_wordoffsets, no padding
